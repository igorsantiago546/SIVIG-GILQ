## 📋 Sobre o Projeto
Este projeto utiliza técnicas de **Machine Learning** com foco na detecção precoce de casos suspeitos de agravos de
notificação compulsória. O objetivo é auxiliar na tomada de decisão em saúde pública, permitindo que recursos sejam direcionados de forma eficiente para áreas ou indivíduos de maior risco.

### 🧬 Contexto do Problema
Nos serviços de pronto atendimento, grande parte dos pacientes
chega com sintomas inespecíficos, como febre, cefaleia e vômitos.

Esses sintomas podem representar:

um caso simples, ou o início de um agravo grave de interesse epidemiológico.

Problema: A triagem clínica não possui um mecanismo padronizado e automatizado para identificar, em tempo real, casos suspeitos epidemiológicos, o que pode atrasar a notificação e a investigação.
